# Native Rust Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a native Rust implementation of TradingAgent beside the current Python runtime, preserving v0.6 behavior, the already-ported crypto capabilities, and the remaining Tomortec core features identified in the audit.

**Architecture:** Add a Rust workspace under `rust/` with core, data, LLM, reporting, and CLI crates. The core uses typed serde state and a Tokio workflow rather than cloning LangGraph internals; vendor and model SDKs stay behind project-owned traits. Python remains the reference runtime until deterministic parity tests pass.

**Tech Stack:** Rust 2024; Tokio; serde/serde_json; chrono; rust_decimal; reqwest; async-trait; thiserror; schemars; clap; tracing; sha2; tempfile; mock HTTP server tooling.

**Spec:** `docs/superpowers/specs/2026-10-06-rust-port-design.md`

## Global Constraints

- Rust code lives under `rust/`; Python production entry points remain unchanged during this plan.
- Email and PDF generation are out of scope.
- Historical runs cannot consume live/current-only crypto data; enforcement lives below agents.
- Checkpoints/state use an explicit schema version and reject incompatible versions.
- Secrets and credential-bearing URLs never persist in reports, logs, checkpoints, or run metadata.
- Preserve `Buy / Overweight / Hold / Underweight / Sell` plus explicit `Review` semantics when no valid rating can be produced.
- Preserve quick/deep model tiers, with independent provider/model/base URL per tier.
- Required LLM families: OpenAI-compatible (including Qwen/DashScope/Gitee/OpenRouter-style endpoints), Anthropic, Google, Azure OpenAI, Bedrock.
- Required general data families: Yahoo, SEC EDGAR, Alpha Vantage, FRED, Polymarket, Reddit/Stocktwits-equivalent social context.
- Required crypto families: Binance USD-M futures, TAAPI, Alternative.me, CoinStats, CoinDesk, BlockBeats, Reddit-equivalent context.
- Trader output: action, reasoning, entry, support, resistance, take-profit, stop-loss, position sizing; insufficient evidence yields `None`, never invented prices.
- Investment preferences, external reports, and portfolio context remain distinct inputs.
- Merge gate: `cargo fmt --check`, `cargo clippy --workspace --all-targets --all-features -- -D warnings`, `cargo test --workspace`, plus current Python CI commands.

## Review Focus

1. **Date rollover:** live-only providers return `WithheldHistorical` whenever the requested date is historical under the configured runtime timezone, including UTC/local rollover boundaries. Covered in Task 3.
2. **Hostile external reports:** pasted instructions remain untrusted evidence and cannot become system instructions. Covered in Tasks 2 and 7.
3. **Malformed financial values:** percentages/ranges/NaN/infinity cannot silently become absolute price fields. Covered in Task 2.
4. **Credential leakage:** auth headers, query keys, and credential-bearing base URLs are redacted from diagnostics and persistence. Covered in Tasks 6 and 9.
5. **Stale resume:** analyst/debate/provider/model/endpoint/language/portfolio/preferences changes invalidate checkpoints. Covered in Task 9.
